# SM-Skoleskema – drag & drop

Filer:
- index.html: Dagens skema (med ny knap "Byg skema")
- builder.html: Visuel skemabygger med 30-minutters felter
- manifest.json: PWA manifest
- sw.js: Service worker
- skoleskema192.png / skoleskema512.png: ikoner

Brug:
1. Upload alle filer til samme mappe på GitHub Pages.
2. Åbn index.html.
3. Tryk "Byg skema".
4. Opret fag i fagbanken og træk dem ind i skemaet.
5. Tryk "Gem skema".

Data gemmes i browserens localStorage.
